Team Members

To add a new team member: Supabase Dashboard → Authentication → Add user (with email + password). They'll appear here automatically — just set their role below.
RTM Access: leave as "All" for a user to see everything, or restrict them to specific RTM categories — they'll only see data (Dashboard, Inventory, Search, Export) tied to those categories. Applies to non-admin roles; admins always see everything.
